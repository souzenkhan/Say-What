# Accessibility Details to the Wireframes

This wireframe update adds accessibility-focused design choices for older adults and users with hearing impairment.

## Accessibility Changes Added

- Large, easy-to-tap buttons
- Clear status labels such as connection state messages
- Simple and direct error messages
- Less cluttered layouts
- Visual cues that do not rely only on sound
